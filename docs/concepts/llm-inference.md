# LLM Inference (Concept Note)

LLM inference is the process of generating output tokens from a trained model given an input context.

Key topics this lab will study:
- latency vs throughput trade-offs
- memory footprint (VRAM/RAM) under different configurations
- prompt/context effects on generation behavior
- runtime differences across candidate inference engines

This note is educational and planning-oriented; no runtime is selected yet.
